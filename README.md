# Red Point - OpenGL Project

A simple OpenGL program that draws a single red point on a black background using GLUT.

## Files

- `Point.cpp`: Main source code file containing the OpenGL rendering logic.

## How to Compile and Run

Make sure you have GLUT installed (e.g., FreeGLUT).

### On Linux:
```bash
g++ Point.cpp -lglut -lGLU -lGL -o redpoint
./redpoint
